Privacy Policy

Last updated: 5 October 2026

What Adamastis accesses

With the account owner's consent, Adamastis uses YouTube API Services to access the owner's YouTube channel information, video metadata, playlists, comments and analytics reports.

How the data is used

The data is used only to perform the actions the owner requests: editing videos, playlists and comments, and viewing analytics.

Storage and sharing

Adamastis has no servers. OAuth tokens and data are stored only on the owner's computer. No data is sold, shared with or transferred to third parties.

Adamastis's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

YouTube and Google

Adamastis uses YouTube API Services. By using it you agree to the YouTube Terms of Service. See also the Google Privacy Policy.

Revoking access

Access can be revoked at any time on the Google security settings page.
